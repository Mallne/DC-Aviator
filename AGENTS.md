# Aviator

**Stack**: KMP library. OpenAPI-first API framework using Ktor.

> **Full docs**: [aviator/.ai/](.ai/) | [Notary](https://docs.mallne.cloud/doc/aviator-RdNz6f71NO)

## Critical Rules

1. OpenAPI specs are the source of truth -- all behavior derives from the spec
2. Use `@InternalAviatorAPI` for internal framework APIs
3. All network requests in business logic MUST use Aviator (not direct Ktor)
4. Code in `commonMain` must remain platform-agnostic
5. Use `x-dicentra-aviator-*` extensions only through `AviatorExtensionSpec`

## Build

```bash
./gradlew build
```

### Weaver response execution — current summary (2026-10-26)

- Default `preserveDefaultOutput=false` transforms provider JSON **before `PaintingResponse`**, with exactly one normal adapter decode; `preserveDefaultOutput=true` transforms afterward and retains the original typed result. `transformResponse` stores the transformed `JsonElement` in `context.bundle[RESULT]`.
- Options are JSON-encoded, then decoded with unknown-key tolerance derived from configured JSON; reuse that instance when `ignoreUnknownKeys` is already true. Do not cast `InflatedServiceOptions.optionBundle`, discard configured serialization behavior, or suppress decoding warnings wholesale. Missing schemas skip transformation; options handling remains generic, not provider-specific.
